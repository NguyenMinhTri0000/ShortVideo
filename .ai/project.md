# Project Overview: Short Video Generator & Automation Platform

## Project Purpose
Automated AI short-video creation, product research, script generation, text-to-speech, subtitle synthesis, and multi-platform publishing (TikTok, Reels, YouTube Shorts).

## Architecture Stack
- **Backend**: NestJS (TypeScript), Node.js, Prisma ORM, PostgreSQL, BullMQ, Redis.
- **Engine**: Python 3.12, FastAPI, LiteLLM, MoviePy, Edge-TTS, Faster-Whisper, Pytest.
- **Frontend**: Next.js, React, Tailwind CSS, Lucide icons.
- **AI Integrations**: Gemini, Groq, OpenAI, DeepSeek, Moonshot, Qwen, Azure, Edge-TTS.
- **Infrastructure**: Docker Compose, PostgreSQL, Redis.
